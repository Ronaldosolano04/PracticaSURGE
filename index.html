De tu computadora a internet en cuatro pasos

El flujo completo de integración y despliegue continuo que sostiene este proyecto.

Escribir

Se edita el archivo index.html en VS Code y se guarda el cambio con un commit.

Subir

El commit se envía a la rama main del repositorio en GitHub con git push.

Automatizar

GitHub Actions detecta el push y ejecuta el workflow definido en main.yaml.

Publicar

Surge.sh recibe los archivos y actualiza el sitio con la nueva versión.

Despliegue

Seguridad sin exponer credenciales

El token de Surge vive como secret cifrado en GitHub. Nunca aparece en el código ni en el repositorio público.

  • El workflow se activa solo con push a main.
  • El token se lee desde secrets.SURGE_TOKEN.
  • Cada ejecución queda registrada en la pestaña Actions.
name: Deploy a Surge

on:
  push:
    branches: [ main ]

jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
      - run: npm install --global surge
      - run: surge ./ tu-dominio.surge.sh
          --token ${{ secrets.SURGE_TOKEN }}
